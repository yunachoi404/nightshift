# Installed Mac app judge run, October 19, 2026

This run uses the real engine in mock runtime mode, with real editor exports. No GPU generation, Spark use or model downloads. The editor used the existing local caption tools. The app runs from `/Applications/Nightshift.app`, installed from the arm64 DMG. Test data is isolated in `~/Library/Application Support/Nightshift QA 2026-10-19`.

Apple M4 Max, 128 GB unified memory. The hardware probe detected the chip and memory correctly. Node 24.19.0 in the installed Electron runtime. `NIGHTSHIFT_MOCK_SPEED=0.1` shortens simulated generation waits. It does not replace editor rendering.

These do not block the tested demo workflow. No engine, editor or contract files were edited.

- Engine export jobs omit file size from the completion message. Duration, dimensions and caption method are present. The UI shows the message unchanged. Example is visible in [portrait ad result](e2e/product-export9.jpg). File sizes are recorded independently in export-verification.json.

- Wide mock source videos have a burned-in FINAL label. Center cropping to portrait cuts that label off. Real export title cards and captions fit. This belongs to engine placeholder generation. [Portrait example](e2e/player-cinematic2.jpg).
- The live editor previews the cut and captions. Template title and end cards, dissolves and the finished audio mix are verified in the MP4. It does not yet draw the full export composition live.
- Mac model generation and real model installs were excluded as requested. The Apple recipe is estimated; Remaster is unavailable and disabled with an explanation. Instrumental mock music does not test sung-word recognition.
- Locking worked. Drag reorder and minimum native window sizing were not separately verified. The 1280 browser check is a responsive-layout check, not a native window-size test.
