# Hackathon rules (read live 2026-10-17)

Page: https://comfy.org/open-source-higgsfield

## App requirements (page accordion; its text ships only in the site's translations JS bundle,
## the accordion does not open in a browser)
Every submission must include:
1. Built using the Comfy Developer Platform (**Comfy Router and/or Comfy SDK**,
   https://docs.comfy.org/development/api-development/sdks).
2. Repo with an open-source license and enough setup detail that someone else can run it on their own machine.
3. Any other tools, models or techniques are fair game and must be explained in the demo video.
4. Lawful, SFW, no unlicensed IP or likenesses.
5. ComfyUI, NVIDIA, Runpod, LTX, Black Forest Labs and MiniMax may feature it with credit.
6. One submission per person.

## Prepare your submission
- GitHub repo: app code, workflow files, open-source license, instructions to run it locally.
- Demo video: two minutes max, "in case we can't get it running ourselves".
- A link to try it: optional, strongly encouraged. The deployed app or endpoint.
- Social post: the demo video on Reddit, X, IG, LI, YT or TikTok tagging #OpenSourceHiggsfield.

## Submit form (https://form.typeform.com/to/V1dSQrkS), fields
- Name, Comfy app email, country, socials, Discord, Reddit usernames
- ComfyUI familiarity
- Project name, one-line description (100 chars max)
- GitHub repo URL: public, open-source license, setup instructions
- Demo video URL: "show us your build in action and how you built it in <2 mins"
- Live link to try it: optional but strongly encouraged. Not public. Expect 5-10 judging runs.
  Rate-limiting or capping spend is fine.
- Social post link tagging #OpenSourceHiggsfield (X, IG, Reddit, TikTok...)
- Which parts of ComfyUI: Comfy API, Comfy Router, Comfy SDK, Comfy Cloud Agent, Comfy Local Agent, Comfy MCP
- All generative models used; other tools
- Categories: Most Innovative, Most Viral, Open Weights Only, Built with FLUX 3 Bonus, VFX Built with LTX Bonus
  (Best Overall is automatic. MiniMax H3 bonus is on the page but not on the form.)
- "Is your stack fully open?" Yes = every model, node and dependency open; no closed API in the
  critical path. Rented GPUs still count.
- Agreements: public repo with OSS license; lawful, SFW, no unlicensed IP or real people's likeness
  without permission; Comfy/NVIDIA/Runpod/partners may feature it; **this is my only submission**.

## Prizes
Best Overall $10k. Most Innovative / Most Viral / Open Weights Only: RTX 5090 each
(Innovative demo must explain why it's innovative). 10 runner-ups $250 credits.
Bonuses: LTX VFX $2k cash (LTX core video model), FLUX 3 $1k/$500/$250 credits, MiniMax H3 $1k credits.
One entry can win a main category plus a bonus.
