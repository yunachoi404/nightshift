### Same-take check

The draft and final show the same woman, framing, walk, reflection, street geometry, and camera path at matching frames. Downscaling the final to 640x384 gives average SSIM 0.872052 against the draft. First-frame SSIM is 0.939653. The final adds detail; it is not pixel-identical to the draft. The contact sheets support calling this a continuation of the same take on this sample. They do not establish a guarantee for every prompt.

Core `SaveLatent` cannot save ComfyUI's joint AV wrapper. Nightshift's own nodes store both streams, masks, dtypes, and JSON metadata in safetensors. A CPU regression proves exact tensor round trips. The checkpoint loader derives width and height from the saved video stream and restores saved fps. Existing 24 fps checkpoints remain readable. The final must receive the draft's original prompt, negative prompt, seed, and image. Changing that conditioning can change the result.

CPU waveform inspection exposed an audio difference in the first final. The joint stage-2 sampler also regenerated audio. The v2 same-take graph decoded audio directly from the saved draft audio stream, while still supplying both streams to stage 2. ## Portable node installation

`comfy_nodes/nightshift/install_upstream.py` installs pinned open-source Breeze, MOSS and Kandinsky node code from upstream into the target ComfyUI, applies our packaged fixes, and handles nested plugin roots. It downloads no model weights and never installs Fish code. Setup scripts call it. Filesystem integration tests cover the actual installer with stubbed network and dependency commands, repeat installation, nested roots, and refusal to modify another known ComfyUI on the box or externally linked node directories. A full fresh ComfyUI install is not claimed.

The engine installer still needs to call this standalone hook after linking our node pack and installing core dependencies, before starting ComfyUI. Call `<comfy-python> <nodesDir>/nightshift/install_upstream.py --comfy-dir <comfyDir> --uv <uv> --workflows <recipe workflow basenames...>`. Attach-mode Spark already has these nodes. This integration is engine work; no package code was changed here.
