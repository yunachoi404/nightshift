# Fonts

Bundled with the app. Nothing loads from the network at runtime.

| File | Family | Use | License |
|---|---|---|---|
| `young-serif-latin.woff2` | Young Serif, by Bastien Sozeau | Headlines: setup, page titles, sheets, empty states | SIL OFL 1.1, `OFL-YoungSerif.txt` |
| `sedgwick-ave-latin.woff2` | Sedgwick Ave, by Kevin Burke | The one handwritten note: the tape label on the welcome window | SIL OFL 1.1, `OFL-SedgwickAve.txt` |

Both are the Latin subsets served by Google Fonts. Everything else is the system face.
