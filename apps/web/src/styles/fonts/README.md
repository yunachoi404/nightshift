# Fonts

Bundled with the app. Nothing loads from the network at runtime.

| Family | Use | Source | License |
|---|---|---|---|
| Inter, by Rasmus Andersson | The work: every control, list, field and paragraph | `@fontsource-variable/inter` (opsz axis) | SIL OFL 1.1 |
| Fraunces, by Undercase Type | Headlines at weight 600: page titles, the brand name, setup, sheets, empty states | `@fontsource-variable/fraunces` (opsz axis) | SIL OFL 1.1 |
| JetBrains Mono, by JetBrains | Keys, counts, time codes and dimensions | `@fontsource-variable/jetbrains-mono` | SIL OFL 1.1 |
| Sedgwick Ave, by Kevin Burke | The one handwritten note: the tape label on the welcome window | `sedgwick-ave-latin.woff2` here, the Latin subset served by Google Fonts | SIL OFL 1.1, `OFL-SedgwickAve.txt` |

The Fontsource packages carry their own license files. `styles/tokens.css` imports them.
